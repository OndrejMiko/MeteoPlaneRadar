# Screen previews

Firmware 0.8.9. Generated from host-fixture SVG drawing calls with synthetic data.
No live calendars, chat messages, tokens or subscription URLs are used.
Smooth text uses the firmware bitmap fonts; built-in pixel text is approximated by the host font.
Weather uses the real chrome on a synthetic grid, not a radar download.
The banner composites the real notification layer over the clock; expanded details replace the screen.

Regeneration: see [tests/README.md](../../tests/README.md).
